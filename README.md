CPU Process Scheduling Algorithms

This project implements six fundamental CPU scheduling algorithms used in Operating Systems to manage process execution and CPU resource allocation.

Implemented Algorithms:

FCFS (First Come, First Served): Executes processes in their order of arrival.

SJF (Shortest Job First): Selects the process with the shortest CPU burst time.

SRTF (Shortest Remaining Time First): A preemptive scheduling algorithm that prioritizes the process with the shortest remaining burst time.

Round Robin (RR): Allocates a fixed time quantum to each process, ensuring fair CPU sharing.

Preemptive Priority Scheduling: Allows higher-priority processes to interrupt currently running lower-priority processes.

Non-Preemptive Priority Scheduling: Executes processes based on priority without interrupting the currently running process.

Project Objectives:

Understand different CPU scheduling techniques.

Analyze process execution and scheduling behavior.

Calculate waiting time and turnaround time.

Compare the performance of different scheduling algorithms.

Strengthen practical knowledge of Operating Systems concepts.
